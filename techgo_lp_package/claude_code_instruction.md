# Claude Code 実装指示書：TechGO 単体推し 記事LP

## 目的
Google検索広告から流入する「年収アップが本音だが、まだ転職意欲が顕在化しきっていない実務経験2年以上のITエンジニア」を、TechGOの無料相談CVへ誘導する記事LPを作成してください。

## 想定流入KW
- エンジニア 評価されない
- エンジニア 年収 低い
- エンジニア 昇給しない
- エンジニア 市場価値
- エンジニア キャリアアップ
- ITエンジニア 市場価値
- ITエンジニア 年収アップ
- エンジニア 3年目 転職
- Java エンジニア 年収
- Java エンジニア 転職

## LPの中核コンセプト
「あなたの実力が評価されていないのではありません。今の会社だけで、あなたの価値を決めていませんか？」

ユーザーに持ち帰らせる感情は以下です。
1. このままだと損しているかもしれない
2. もっと評価される会社があるかもしれない
3. 転職するかは別として、一度プロに市場価値を確認してもいいかもしれない

## 共通敵の置き方
競合エージェントや大手転職サイトを名指しで否定しないこと。
共通敵は「求人を見るだけで自分の市場価値を分かった気になること」「準備不足のまま面接に進むこと」「スキルがあるだけで評価されると思い込むこと」に置く。

NG：大手転職サイトはダメ、他社エージェントは使うな
OK：求人を見るだけでは、あなたの経験をどう評価される形で伝えるべきかまでは分からない

## デザイン方針
- 記事LPだが、SEO記事ではなく広告流入向けのセールスレター寄り
- 1ブロックは短く、スクロールしやすい
- 見出しでストーリーが追えるようにする
- 信頼性を上げるために出典付きの図表を入れる
- 文字だけでなく、比較図・フロー図・カードUIを使う
- トーン：誠実、知的、押し売り感なし
- カラー：黒/濃紺ベース + アクセントに緑または青
- CTAは「無料相談」「市場価値を相談する」に寄せる。「今すぐ転職」は強く出しすぎない

## ページ構成

### 1. ファーストビュー
対象者を明確にする。

見出し：
実務経験2年以上のITエンジニアへ
「もっと評価される会社があるかもしれない」と思ったことはありませんか？

サブ：
今の会社で評価されていないからといって、あなたの市場価値が低いとは限りません。同じ経験でも、会社・職種・評価制度・伝え方によって、年収レンジは大きく変わります。

CTA：
無料で市場価値を相談する

補足：
転職するかどうかは、相談してから決めれば大丈夫です。

### 2. この記事で分かること
箇条書きカードで表示。
- なぜ同じエンジニア経験でも年収差が生まれるのか
- 今の会社の評価と転職市場での評価がズレる理由
- 求人を見るだけでは市場価値が分からない理由
- 経験者エンジニアが転職で損しやすいポイント
- なぜTechGOが年収アップを目指すエンジニアと相性が良いのか

### 3. 共感セクション
見出し：
頑張っているのに、評価が年収に反映されていないと感じていませんか？

チェックリスト：
- 毎年昇給しても数千円〜1万円程度
- 担当範囲は広がったのに給与は変わらない
- 同期や知人エンジニアの年収を聞いて焦った
- このまま今の会社にいていいのか不安
- 転職したい気持ちはあるが、自分の市場価値が分からない

### 4. 教育1：年収は能力だけで決まらない
見出し：
エンジニアの年収は「能力」だけで決まりません

本文：
年収は、スキルだけでなく、会社の給与テーブル・利益率・評価制度・担当案件によって変わります。厚生労働省Job Tagでは、ITSSレベル別の年収レンジに大きな幅が示されています。

図表：`assets/figure_01_itss_salary_range.svg`

出典：厚生労働省 Job Tag「プログラマー」「システムエンジニア（Webサービス開発）」

### 5. 教育2：社内評価と市場評価は一致しない
見出し：
今の会社の評価と、転職市場での評価は一致しないことがあります

本文：
社内では「普通の保守運用」と見られている経験でも、転職市場では「障害対応」「改善提案」「顧客折衝」「レビュー・育成」などの経験として評価されることがあります。

具体例カード：
社内での見られ方：保守運用を担当
市場での見られ方：障害対応、原因調査、改善提案、顧客折衝、レビュー経験あり

図表：`assets/figure_02_internal_vs_market.svg`

### 6. 教育3：求人を見るだけでは市場価値は分からない
見出し：
求人票に「年収700万円」と書かれていても、自分がその年収で評価されるとは限りません

本文：
企業が見ているのは使用技術だけではありません。どんな課題を解決したか、どの範囲まで任されていたか、なぜその技術を選んだのか、面接で再現性を説明できるかが見られます。

強調コピー：
スキルがあることと、スキルを評価される形で伝えられることは違います。

### 7. 共通敵：求人だけ見て準備不足のまま進むこと
見出し：
一番もったいないのは「求人を見ただけ」で転職活動を始めてしまうこと

本文：
大手転職サイトやスカウトサービスで求人を見ること自体は悪くありません。ただし、求人を見るだけでは、自分の経験をどう武器にするかまでは分かりません。

必要な準備：
- 経験の棚卸し
- 職務経歴書の見せ方
- 面接での伝え方
- 企業ごとの評価ポイントの把握
- 年収交渉を見据えた選考対策

### 8. 解決策：経験者向けエージェント
見出し：
だから、経験者向けエージェントという選択肢があります

本文：
実務経験2年以上のエンジニアは、ポテンシャルではなく「これまで何をして、次に何ができるか」を見られます。だからこそ、求人紹介だけでなく、経験の棚卸し・面接対策・企業別の選考準備まで支援してくれるエージェントを選ぶ意味があります。

図表：`assets/figure_03_value_communication_flow.svg`

### 9. なぜTechGOなのか
見出し：
年収アップを目指す経験者エンジニアに、TechGOが相性の良い理由

理由カード：
1. 実務経験2年以上のITエンジニア向け
2. 模擬面接は回数制限なし
3. ITコンサル・メガベンチャーなど高年収求人に強い
4. 土曜1Day選考会で忙しい人も進めやすい
5. エージェント側にもエンジニア経験者・IT企業経験者などのバックグラウンドを持つ人が多く、エンジニア目線で対策しやすい

注意：5はユーザー提供情報ベース。実装時は「多い」と断定する場合、広告主資料や公式情報で確認できる範囲に合わせること。確認できない場合は「エンジニア/IT企業経験を理解したアドバイザーが支援」のように表現を弱める。

### 10. 最終CTA
見出し：
転職するかどうかは、市場価値を知ってから決めても遅くありません

本文：
今の会社だけを基準に、自分の価値を決めてしまうのはもったいないかもしれません。まずは、あなたの経験が転職市場でどう評価されるのかを確認してみませんか？

CTA：
TechGOで無料相談する

## 実装要件
- モバイルファースト
- FV CTA、記事中 CTA、最終 CTA を設置
- CTAボタンは全て同一リンク変数 `TECHGO_AFFILIATE_URL` を使う
- 図表はSVGをimgタグで読み込み、altを入れる
- 出典はセクション下部に小さく表示
- 誇大表現を避ける。「必ず年収アップ」などは書かない
- 「可能性があります」「ケースがあります」などの表現を使う
- Google広告審査に通りやすいよう、断定・煽りすぎ・他社誹謗は避ける

## CTAリンク差し替え箇所
`TECHGO_AFFILIATE_URL = "ここにASPのアフィリエイトリンクを入れる"`
